# local-repo-monitor

A light-weight web application which provides a simple interface over your local repositories, it keeps track of their git status, any staged/un-staged changes, branches etc... This tool is intended to be run as a Docker Container that sit's in the background performing periodic health fetches.

This application is mostly generated by Opus 5.6, however, I have reviewed every line of the actual implementation as well as the UI choices .

Feel free to clone this repo and make any changes that can help with your workstation.
